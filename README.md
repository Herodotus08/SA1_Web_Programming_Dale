# Web Programming SA1

A collection of exercises completed for a Web Programming course, focused on HTML and CSS fundamentals.

## Exercises
- `exercise-1-semantic-markup` - Semantic HTML structure
- `exercise-2-css-styling` - CSS styling techniques
- `exercise-3-page-layout` - Page layout design
- `exercise-4-web-accessibility` - Web accessibility best practices

## Tech Used
- HTML5
- CSS3

## How to Run
Open any exercise folder and load its HTML file in a browser. No build steps or dependencies required.
